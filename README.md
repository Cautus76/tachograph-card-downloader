# Tachograph Card Downloader

Experimental open-source Python utility for downloading signed DDD files directly from European tachograph driver cards using a PC/SC-compatible smart-card reader.

The project currently supports Gen1 and Gen2 card applications. The first verified configuration is macOS, Python, pyscard, an Alcor Link AK9563 reader, and a Generation 2 version 1 driver card.

## Status

Work in progress. The tested downloader source code and full English and Czech documentation will be added after final verification.

## Privacy warning

DDD files contain personal identification information and detailed driver activity. Never publish real DDD files, card certificates, card numbers, names, or activity records.
